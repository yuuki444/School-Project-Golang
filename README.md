# «SchoolHub» — Электронный дневник

Веб-приложение «Электронный дневник», построенное на базе **Go (Golang)** для серверной части и **HTML5/JavaScript** для клиентской части. Проект поддерживает полноценную REST API аутентификацию, CRUD-операции для управления школьным процессом (ученики, учителя, предметы, оценки, домашние задания) и **realtime-обновления в реальном времени с помощью WebSocket**.

---

## Основные возможности

* **Аутентификация и безопасность:** Регистрация, авторизация по email/паролю и защита приватных эндпоинтов с помощью bearer-токенов (`Authorization`).
* **Управление учениками (CRUD):** Создание, просмотр списка (с фильтрацией по классам), редактирование и удаление учеников.
* **Учителя и Предметы:** Добавление преподавателей и привязка к ним учебных предметов.
* **Электронный дневник:** Выставление оценок (от 1 до 5) и просмотр оценок конкретного ученика с возможностью фильтрации по предметам.
* **Домашние задания:** Публикация заданий с датами выдачи и дедлайнами.
* **Real-time уведомления (WebSocket):** Автоматическое обновление данных на странице (дневник, списки учеников, домашние задания) без необходимости перезагружать страницу или нажимать клавишу `F5` при поступлении событий от сервера.

---

## Технологии

* **Backend:** Go (net/http, встроенный маршрутизатор Go , потокобезопасное хранилище в памяти с `sync.Mutex`).
* **WebSockets:** библиотека `github.com/gorilla/websocket`.
* **Frontend:** Чистый HTML CSS

1. Клонируйте репозиторий или скачайте файлы проекта (`main.go` и `index.html`) в одну папку.

   ```bash
